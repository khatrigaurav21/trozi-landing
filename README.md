# Trozi landing page

Static, single-file landing page for Trozi (index.html, no build step).
Hosted as a Render static site (publish directory: repo root).

- "Join the beta" posts to the API: `POST https://career-mate-api.onrender.com/waitlist`
  with `{ email, platform: "ios" | "android", source: "landing" }`.
- Brand assets come from `brand/trozi/` in the Career Mate folder (v2 mark, larger eyes).
- og-image.png is the 1200×630 share image.
